# 册页 v0.1.0 — 原生预发布版

本版本开始提供可安装的 Android 原生应用，最低 Android 11，目标 Android 16。界面采用已确认的白灰蓝设计，设置仅保留归档相册与照片权限。

## 已实现

- 读取设备本地图片和已有相册，建立首次历史基线，识别后续新增图片。
- 收件箱固定清单、单张/网格分类、日期多选、长按范围选择/取消和边缘滚动。
- 分类决定本地保存、分批提交、系统写入/回收站授权、执行结果核对。
- 同名冲突追加序号，图片文件内容不变，取消授权保留决定。
- Room 操作记录、中断恢复、待修复、撤销分类及归档撤销计划。
- 相册与照片浏览、缩放/平移/双击、系统分享、历史整理、最近归档。
- 不申请网络权限，不上传照片或分类记录。

## 验证

- 4 项选择逻辑单元测试。
- Android API 37 模拟器上的移动内容一致性、同名不覆盖、数据库重开保持决定、Activity 启动检查。
- Android Lint、Debug 与签名 Release 构建。

## 尚需实机验收

- iQOO 12 / Android 16 尚未连接，系统自带相册展示、权限交互、长按振动和触屏手感尚未完成验证。
- 原生页面已按设计参数实现，但尚未完成所有页面逐像素截图验收，不将本版本标为稳定版。
- 当前前台同步采用轻量全量元数据对账和代际基线判定，未实现大图库的纯增量/分页优化。
- 首版仅支持同卷的现有本地相册；空相册/云相册不一定能被 MediaStore 枚举。
- UI 测试目前覆盖启动；系统授权取消/中断的完整端到端场景仍需真机补测。

测试版本请先使用少量可恢复的照片验证。后续版本保持包名和正式签名，使用覆盖安装保留本地记录。
