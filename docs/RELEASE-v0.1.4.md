# 册页 v0.1.4 — 指定相册后保留选中

## 修复

- 在收件箱选中照片后，指定归档相册会保留原有勾选；无需重新选照片，就能点击另一个相册更改归档位置。
- 手动取消勾选仍可清除选择；仅打开归档确认弹层不会清除选择。
- 点击“确认归档”实际提交非空归档计划时清除选择；系统授权取消后，分类决定仍按原有逻辑保留。
- 单张和网格分类、封面卡片、实际移动及系统回收站操作沿用此前实现。
- 包名和正式发布签名保持一致，versionName 0.1.4 / versionCode 5。

## 验证

- 4 项选择逻辑单元测试、4 项 API 37 模拟器设备测试通过，Android Lint 0 错误，签名 Release 构建通过。
- 连续操作测试通过：选中照片 → 指定相册 → 保留选中 → 改为另一个相册 → 原照片全部更新到新目的地，选中集合保持不变。
- 手动取消后可重新选择；仅打开确认窗口保留选中，实际确认提交后清空选中。
- iQOO 12 / Android 16 覆盖安装成功，确认 0.1.4 / versionCode 5，冷启动成功；本次未提交真机照片移动或回收操作。
- 本版同时包含 v0.1.3 的收件箱提示精简、首图加名字的相册卡片及展开网格。
