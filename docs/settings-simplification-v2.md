# 册页：设置页精简补充规范 v2

日期：2026-11-02。依据用户要求：“设置里面的选项再精简一些，目前选项太多了”。

本补充仅替换原 DESIGN.md 中设置入口及相关功能入口的位置；配色、字号、主页面布局、媒体规则与长按滑选继续沿用已冻结方案。原文档和参考文件保留，本次仅新增修订记录与独立预览。

## 设置页

一级入口只保留两项，整行可点：

1. **归档相册**：副标题显示已选相册数量；进入原有目标相册选择面板。自动归档说明只放在该面板中。
2. **照片权限**：副标题显示真实访问范围；进入权限管理或重新选择流程。预览使用“全部图片”示例状态，不能作为正式权限判断。

去掉“整理规则”“照片与记录”“访问权限”分组标题；去掉“新增图片”“分类方式”等不可调整的规则行；去掉页尾重复规则说明。不增加主题、动画、语言、缓存等新设置。

## 历史与记录入口

相册首页原“管理”文字入口改为 **整理**，打开底部面板，包含：

- **历史整理**：进入主动的历史图片选择/分类会话。
- **最近归档**：查看执行结果和撤销归档。

两项能力保留，不塞入设置页二级菜单。归档目标只在设置中配置，避免重复管理入口；相册页“归档目标”分段仍用于筛选展示。

待修复能力按已确定业务方案保留；有异常时从对应状态提示进入，不为了入口完整而给当前设置再增加一行。

## 视觉尺寸

- 颜色保持 #4967C7 / #FFFFFF / #F6F7F9 等既定 token。
- 页面标题 26sp、文字 14sp、状态说明 12sp。
- 列表左右边距 20dp，距离标题区域 16dp。
- 每行最小高度 76dp、上下内边距 16dp，使用现有细分隔线。
- 行尾箭头 18dp。整行作为操作区域，保持无障碍标签。
- 页尾仅显示小型应用名“册页”，不添加规则说明或多余功能。

## 核对项目

- 设置一级列表恰好两项，进入/返回正常。
- 归档相册勾选变化后，设置页数量同步变化。
- 照片权限入口仍可使用。
- 相册页能进入历史整理和最近归档。
- 其他分类页面和既有滑选行为保持。
