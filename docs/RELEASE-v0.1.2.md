# 册页 v0.1.2 — 直接使用手机已有相册

## 调整

- 删除首次使用时的“选择归档相册”步骤，照片授权后直接进入应用。
- 删除设置中的“归档相册”、相册预选弹层以及相册页的“归档目标”筛选；设置仅保留照片权限。
- 分类页直接提供手机已有本地相册：前四项作为快捷入口，“全部相册”展示完整可用列表。
- 停用旧版预选相册的自动归档规则。新增图片不论来自哪个本地相册，仍进入收件箱；成功移动或移入回收站后视为已处理。
- 保留已有分类状态、待提交决定、操作记录、历史基线及照片授权；旧预选配置不再生效。
- 全新安装仍默认从现在开始，第一次读取时建立历史基线，无需确认配置；旧照片可通过历史整理入口处理。
- 沿用正式发布签名和包名；versionName 0.1.2 / versionCode 3。

## 验证

- 4 项选择逻辑单元测试、4 项 API 37 模拟器设备测试通过，Android Lint 0 错误，签名 Release 构建通过。
- 启动测试覆盖系统权限弹窗、拒绝重开不重复弹窗、授权后直接浏览、设置无归档相册项、相册页无归档目标筛选，以及完整相册分类列表。
- 测试注入旧预选相册配置后，新增到该相册的图片仍为 pending，证明旧配置不会跳过收件箱。
- iQOO 12 / Android 16 从 v0.1.1 覆盖安装成功，版本号确认 0.1.2 / versionCode 3；冷启动成功，实机截图确认系统照片权限弹窗覆盖在收件箱上。
- 未在真机移动或删除用户照片；真机相册列表等待用户完成当前权限选择后体验。

## 已知范围

相册列表来自授权范围内的 MediaStore 本地图片，系统相册中的云端、私密或空相册不保证可枚举；仍只支持同存储卷移动。大图库性能与全页面逐像素验收继续沿用此前预发布版的限制。
