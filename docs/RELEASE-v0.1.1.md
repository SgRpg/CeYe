# 册页 v0.1.1 — 系统照片权限弹窗

## 本次调整

- 首次打开收件箱时直接请求 Android 系统照片权限，移除独立的“先允许册页访问照片”页面。
- 拒绝后保留收件箱空状态和顶部简短授权入口，重开应用、重建页面均不会自动重复请求。
- 用户主动重试时再次请求系统权限；系统已禁止再次询问时，入口转到应用权限设置。
- 支持全部图片和用户选定图片两种授权范围；从系统设置返回时重新检查权限。
- 授权成功后继续原有的归档相册选择流程。已授权用户升级后直接使用，不重复询问。
- 包名与发布签名保持一致，版本号 0.1.1 / versionCode 2，支持从 v0.1.0 覆盖安装。

## 验证记录

- 4 项选择逻辑单元测试通过；Android Lint 0 错误；签名 Release 构建通过。
- Android API 37 模拟器上 4 项设备测试通过：实际相册移动及内容一致性、同名不覆盖、分类决定持久化、系统权限流程。
- 权限流程覆盖首次系统弹窗、拒绝后重开和页面重建不重复弹窗、主动重试、授权后进入归档相册选择、已有授权时重开不重复询问。
- iQOO 12 / Android 16（API 36）从 v0.1.0 覆盖安装成功，确认 versionCode 2、versionName 0.1.1，冷启动成功。
- 真机已有全部照片权限，本次保留该授权；真机的首次系统授权弹窗未通过清除数据或撤销权限方式重测。未在真机移动或删除用户照片。

## 范围

本版本集中调整权限入口。原有照片分类、系统相册移动、浏览和简化设置保留。仍为预发布版本，大图库性能与全部页面的逐像素验收继续沿用 v0.1.0 的已知限制。
