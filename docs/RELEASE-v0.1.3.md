# 册页 v0.1.3 — 相册封面卡片

## 调整

- 收件箱删除“本次 × 张／× 张待提交”和长按滑动操作说明，保留已选数量、全选及日期分组操作。
- 删除“归入相册”标题，保留右侧“全部相册”入口。
- 折叠相册入口改为一行封面卡片，按当前可用宽度展示能完整容纳的数量，不再固定四个纯文字按钮。
- 卡片以相册当前照片排序的第一张可见图片作封面，相册名以白字叠在左下角，底部渐变确保清晰；不增加相册图片数量提示。
- 点击“全部相册”后展开同样式的封面卡片网格，可上下滚动；点击卡片保存分类决定，提交移动的流程保留。
- 包名和正式发布签名保持一致，versionName 0.1.3 / versionCode 4，支持覆盖安装。

## 验证

- 4 项选择逻辑单元测试、4 项 API 37 模拟器设备测试通过，Android Lint 0 错误，签名 Release 构建通过。
- 设备测试覆盖指定文字消失、已选数量与全选保留、折叠卡片数量按宽度计算且保持正方形、展开网格、滚动至末尾相册并点击保存分类决定。
- 通过合成图片截图检查折叠一行与展开网格的封面、名字、渐变和布局。
- iQOO 12 / Android 16 覆盖安装和冷启动验证；实机已检查收件箱提示移除及真实本地相册封面显示。长相册名使用单行省略，避免拆成孤立字母。
- 真机验证不提交照片移动或回收操作，保留用户原有分类决定和照片。

## 范围

本版调整收件箱中的分类相册入口，日常浏览相册页保持原有布局。相册读取范围、同卷移动和大图库性能限制沿用此前预发布版。
