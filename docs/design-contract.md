# 设计确认记录 v1

日期：2026-11-02。目标：为 iQOO 12 / Android 16 开发本地照片分类与浏览 App。受众：希望通过打开 App 时的整理流程保持相册有序的用户。

## 确认依据

| 依据 | 类型 | 约束 |
|---|---|---|
| 用户确认“前端页面设计按照这版进行……严格按照图片……包括大小，间距，颜色” | provided | 设计冻结，不再重新设计 |
| 用户拒绝薄荷绿，随后确认中性白灰/蓝色版本 | provided | #4967C7 主色，中性白灰背景 |
| 已接受的含长按滑选草案 | observed | `design-reference/approved-ui-v1.html`，完整 CSS/DOM/交互 |
| 目标设备 iQOO 12、Android 16 | provided | API 36 实机验证 |
| CSS 尺寸映射 dp，字号映射 sp，参考宽 390 | inferred | 跨浏览器/Android 的落地规则；实机逻辑屏宽未采集 |
| 系统字体和原生系统栏适配 | inferred | 需要截图校准，不宣称物理像素无条件一致 |

最终方向：严格复刻既有白灰蓝设计，以照片为主体。Compose 提供原生结构和交互，应用自定义 token 控制视觉，避免组件库默认主题改变已确认方案。
